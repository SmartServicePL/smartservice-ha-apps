# Smart Service — aplikacje do Home Assistant

**Home Assistant bez nauki.** To repozytorium dodaje do Home Assistant aplikację **Smart Service HA**. Z niej jednym przyciskiem instaluje się **MIGIELS**.

## Instalacja

1. Otwórz link „Zainstaluj Smart Service HA” albo zeskanuj kod QR ze strony [smartservice.net.pl](https://smartservice.net.pl).
2. Home Assistant zapyta o dodanie repozytorium: kliknij **Dodaj**.
3. Kliknij **Zainstaluj**, potem **Uruchom**.
4. Dalej prowadzi Smart Service HA.

Wymagania:
- Home Assistant OS albo Supervised;
- 64-bitowy system (`aarch64` albo `amd64`);
- Home Assistant w wersji co najmniej 2025.10.

## Aplikacje

| Aplikacja | Opis |
|---|---|
| Smart Service HA | Cały dom w prostym panelu: panel na telefon, moduły, bezpieczeństwo, integracje i pomoc Smart Service. |
| MIGIELS | Menedżer instalacji grzewczej i energii. Instaluje go Smart Service HA. |

Pomoc: [smartservice.net.pl](https://smartservice.net.pl)

## English

**Home Assistant without learning.** This repository adds the **Smart Service HA** app to Home Assistant. **MIGIELS** is then installed from it with one button.

Installation:
1. Open the “Install Smart Service HA” link or scan the QR code on [smartservice.net.pl](https://smartservice.net.pl).
2. Home Assistant asks to add the repository: click **Add**.
3. Click **Install**, then **Start**.
4. Smart Service HA guides you from there.

Requirements:
- Home Assistant OS or Supervised;
- a 64-bit system (`aarch64` or `amd64`);
- Home Assistant 2025.10 or newer.
